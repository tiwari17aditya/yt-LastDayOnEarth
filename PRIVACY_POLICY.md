# Privacy Policy for Last Day on Earth Video Automation

Last updated: October 2, 2026

## 1. Overview
Last Day on Earth Video Automation ("the Application") is an automated personal workflow tool designed to process gameplay screen recordings, add audio soundtracks, generate custom thumbnails, and publish videos to YouTube.

## 2. Information Accessed & Stored
The Application accesses Google APIs strictly for personal workflow automation:
- **Google Drive API**: Reads screen recording video files placed in the designated `Input` folder, moves them to `Processed`, and uploads processed videos to `Output`.
- **YouTube Data API v3**: Uploads processed gameplay videos to the owner's YouTube channel, sets video metadata (title, tags, description, chapters), assigns playlists, and uploads custom episode thumbnails.
- **Gmail API**: Dispatches automated email notifications regarding processing and upload status to the project owner.

## 3. Data Protection & Sharing
- The Application runs locally and on secure scheduled automation runners.
- The Application does **not** collect, store, sell, or share personal data with any third parties.
- OAuth tokens and credentials are used solely to authenticate API requests directly with Google APIs.

## 4. Google API Services User Data Policy Compliance
The Application's use and transfer of information received from Google APIs adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
